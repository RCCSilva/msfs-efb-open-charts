Open Charts - portable (Open Beta)
==================================

For flight simulation only. Use in real-world aviation is prohibited.

1. Extract this folder anywhere (avoid Program Files).
2. Run opencharts.exe. An icon appears near the clock.
3. Click the icon to open the manager. In the Setup tab, install the app into the EFB and,
   optionally, enable "Start with MSFS".

Your data lives in %LOCALAPPDATA%\OpenCharts.
To quit: right-click the tray icon > Quit.

SimConnect.dll is part of the Microsoft Flight Simulator SDK and is used to read the aircraft
position. License: see LICENSE.

Source code and bug reports: https://github.com/RCCSilva/msfs-efb-open-charts
