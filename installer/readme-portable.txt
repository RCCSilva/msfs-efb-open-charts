Open Charts - portable
======================

Apenas para simulacao aerea. E vedado o uso em aviacao real.
For flight simulation only. Use in real-world aviation is prohibited.

PT-BR
1. Extraia esta pasta para um local de sua escolha (nao use Arquivos de Programas).
2. Execute opencharts.exe. Um icone aparece perto do relogio.
3. Clique no icone para abrir o gerenciador; na aba Configuracao instale o app no EFB
   e, se quiser, ative "Iniciar com o MSFS".
Seus dados ficam em %LOCALAPPDATA%\OpenCharts. Para sair: botao direito no icone > Sair.

EN
1. Extract this folder anywhere (avoid Program Files).
2. Run opencharts.exe. An icon appears near the clock.
3. Click it to open the manager; in the Setup tab install the app in the EFB and,
   optionally, enable "Start with MSFS".
Your data lives in %LOCALAPPDATA%\OpenCharts. To quit: right-click the icon > Quit.

SimConnect.dll is part of the Microsoft Flight Simulator SDK and is used to read the
aircraft position. Source code and licence: see LICENSE.
